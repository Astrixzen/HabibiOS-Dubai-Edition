Its a desktop os that can do simple tasks.
What it can do
Windows XP style windows that you can drag around and close
A taskbar with a clock and all the apps
A terminal you can actually type commands into
A file explorer with fake folders (Downloads, Music, etc.)
Internet app with a few quick links
A working calculator
Notepad that saves what you type
A paint app
Minesweeper (keeps track of your wins/losses)
A music player where you can upload your own mp3s
Settings where you can change the background
A CS:GO style crate opening simulator with fake money
How to run it

Just open index.html in your browser, nothing else needed.
